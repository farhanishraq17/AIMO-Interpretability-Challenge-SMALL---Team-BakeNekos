# CLAUDE.md

Workspace for the **AIMO Interpretability Challenge (NeurIPS 2026)**, entered in the **Main Track**
(no size cap; five evaluated models, including `openai/gpt-oss-120b`).

- **Task:** implement
  `are_robust(model_id: str, problems: list[str], reasoning_effort: str = "default") -> list[bool]`.
  For each (model, problem) pair, predict whether that model's answer is **robust** (survives
  answer-preserving perturbations) or **spurious**.
- **What ships today:** *nothing yet.* The Main Track has no submission from us. `PLAN.md` M11a is
  the first ZIP and nothing blocks it.
- **Read `PLAN.md` §0 first** — ten lines of state — then `PLAN.md` §4, the experiment programme.
- **The small track lives in `../AIMO - Interpretability - Small Models track/`.** Four of the five
  evaluated models are its checkpoints, so its shipped policy covers them unchanged.
- **Scoring:** Codabench competition 16180, not Kaggle. Kaggle is only free GPU capacity.
- **Deadlines:** submissions close **1 Nov 2026**; report and open-source code due **15 Nov 2026**.

## Commands

```bash

python scripts/download_data.py

# Build the panel list: originals + the 453 official variant texts -> data/panel/
python scripts/build_items.py

# Regenerate every table in RESULTS.md from data/ and runs/ (~20 s)
python scripts/write_results.py

# Kaggle fleet
python scripts/klarge.py accounts              # which tokens authenticate, and quota
python scripts/klarge.py status [job]          # kernel state; run this before starting anything
python scripts/klarge.py progress [job]        # downloaded completions vs the panel total
python scripts/klarge.py output <job>          # -> runs/<job>/s<i>/
python scripts/klarge.py push <job> --accounts A,B
```

`scripts/klarge.py status` with no argument is the "is anything running?" check, and the answer
belongs in `experiments.md` §2 whenever it changes.

## Invariants that must not drift

- **`train-main-v2`'s label rule is three-valued on `max_drop`**: robust ≤ 0.10, spurious ≥ 0.25,
  unlabelled in between. Never aggregate it with the older `absolute_accuracy_decay` rule for the
  same pair (small track, Finding 44).
- **Robustness is a property of the problem** (LF-12), so a per-problem prediction broadcast to
  every (model, effort) is the default architecture. Anything model-specific has to earn it.
- **Official variant texts are calibration data, never training data.** Our own variants of our own
  pooled problems are training data, which the organizers explicitly allowed on 26 Sep 2026. Keep
  the two in separate files and never concatenate them.
- **Group by problem template, not by text.** `train-main-v2` repeats templates with one constant
  swapped, under different labels (small track, Finding 34).
- **`summary.json`'s `completions_this_session` is the work list length, not the work done**
  (LF-11). Coverage comes from counting records, which `write_results.py` now does.
- **A Main-Track ZIP must not contain `small.txt`** — with it, the score is 0.00.

## Kaggle fleet

Tokens live in this folder's `Secrets.env` (`KAGGLE_USERNAME_<ALIAS>`, `KAGGLE_API_TOKEN_<ALIAS>`).
`scripts/klarge.py` reads them, passes them only through the child environment, and scrubs
token-shaped strings from its own output. **Never print, commit or bundle a token**; scrub
`KGAT_[0-9A-Za-z]+` from anything pasted into a document.

Two GPU sessions and 30 GPU-hours per week per account, T4x2. Caveats that have each cost a run:

- **`NvidiaH100` gives T4x2** on every account tried (LF-3). The AIMO3 H100 notebooks attach the
  AIMO3 competition, and every push that attached it was refused because no account has accepted
  the AIMO3 rules. Accepting them is the account owner's decision.
- **MUBAMAN and Eshad get no GPU** until phone-verified on Kaggle: kernels run on a CPU machine
  with no internet and fail in seconds (LF-5). `jobs/ollama_panel.py` now exits early on a missing
  GPU rather than failing later.
- **The accounts are shared.** RSD and Labib are the same accounts as MEDIUM and CHOTON on a
  teammate's machine; any account running five `kagri-*` kernels refuses new pushes (LF-8).
- **A T4x2 kernel decodes 10–90 tokens/s** depending on the model (LF-11, measured over eight
  jobs). That, not the quota, is why the L1 panel finished one cell of eight.

## Code conventions

- Scripts resolve their own paths (`ROOT = Path(__file__).resolve().parents[1]`), so the working
  directory never matters.
- A job is one plain script in `jobs/`, plus the input files it embeds. `klarge.py` builds the
  kernel; the kernel never reaches out to this repo.
- Record files are append-per-completion JSONL keyed by
  `(problem_id, item_id, sample, effort)`, so a session that dies mid-run resumes instead of
  restarting, and one file name per payload hash so a continuation never overwrites its parent.
- Comments explain **why**, not what. The repo's documents carry the numbers; the code carries the
  reasons a shape was chosen.
- Commit messages: write to a file and `git commit -F` (PowerShell piping adds a BOM).
