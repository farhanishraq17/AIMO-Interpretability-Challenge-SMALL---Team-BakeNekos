## 0. What the Main Track adds, and the cheapest path

The Main Track evaluates five models: the four small-track checkpoints (`Qwen/Qwen3.5-4B`,
`Skywork/Skywork-OR1-Math-7B`, `allenai/Olmo-3-7B-Think`, `deepseek-ai/DeepSeek-R1-0528-Qwen3-8B`)
plus `openai/gpt-oss-120b`, the only one whose `reasoning_effort` varies (`low`, `medium`,
`high` in `train-main-v2`).

The four small models are the same checkpoints in both tracks, so **the small-track solution
covers them unchanged** (E27e/E27h, 0.71 on the small-track leaderboard; E11 v2 at 0.64 as
fallback). **The only new modelling problem is `gpt-oss-120b` x effort.**

Floors (Results, "Official labels"): the best constant per (model, effort) is always "robust".
Over all 71 labelled `train-main-v2` rows it scores **0.732**; for gpt-oss-120b it scores 0.714
(low, 7 rows), 0.667 (medium, 15) and 0.867 (high, 15). A gpt-oss method has to beat those on
37 labelled rows, so its gain must be large to be distinguishable from noise.

## 1. Constraints

- **Evaluation hardware:** one RTX PRO 6000 (96 GB), 3600 s for the whole run; gpt-oss-120b is
  cached in MXFP4 (~62 GiB), so white-box and sampling methods on it are possible at test time.
- **Our hardware:** Kaggle T4x2 only. `NvidiaH100` falls back to T4x2 (LF-3), where gpt-oss-120b
  does not fit. The AIMO3 H100 notebooks attach the AIMO3 competition; every push that tried was
  refused because **no fleet account has accepted the AIMO3 rules**. Accepting competition terms
  is for the account owner to do, not the launcher.
- **Extra-data rule:** our panel's outcomes on the official variant texts are for **calibration
  only**. Labels we derive for official perturbation families must never become training data.
  Training signals come from originals (label-free) and from the official labels themselves.
- **Label rule:** `train-main-v2` is three-valued on `max_drop` (robust <= 0.10, spurious >= 0.25,
  unlabelled between). The reference-problem table uses the older decay rule; never mix the two
  for one pair.
- **Aliases** (`gpt-oss-120b:low`, `qwen3-8b:low`, ...) exist only in public tables and are never
  passed at evaluation.

## 3. Decision gates

| Gate | When | Pass | If it fails |
| --- | --- | --- | --- |
| **G-L1a (proxy fidelity)** | L1 graded | gpt-oss-20b per-variant correct/incorrect agrees with official `gpt-oss-120b:low` outcomes above the majority rate, and DeepSeek-8B with `qwen3-8b:low` | Proxies say nothing about 120b; drop to L3 constants unless L4 unblocks |
| **G-L1b (signal)** | L1 graded | A label-free signal from gpt-oss-20b originals (k=4 answer agreement, trace length, truncation) ranks the 37 labelled gpt-oss-120b rows with AUC >= 0.70 and bootstrap CI lower bound > 0.5 | Ship constants for gpt-oss-120b |
| **G-L3** | Before any upload | Coverage 1.0, 0 invalid predictions, native `bool`s, Docker load test passes | Fix before uploading |

All thresholds above are fixed before any L1 output is read.
